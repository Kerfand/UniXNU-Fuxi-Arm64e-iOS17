# fuxi iOS 17 device results, 2026-11-20 to 2026-11-26

Sources: `a2342fc3f679d6dc7d6c43aa04b2d651c94519f1`. Every run is a temporary boot (`fastboot boot`) of an image built with
`tools/host/build-ios17-kernel.sh` and `tools/host/pack-ios17-hidpath.py`, logs captured from the QUD USB serial console
(`tools/host/fuxi-usb-control.ps1`). Image names are the local `fuxi-ios17-<run>-keepdata-boot-<sha256 prefix>.img`.

| Area | Run | Result |
| --- | --- | --- |
| firmware | every run | DarwinBoot hands off; the kernel prints its banner on the serial console. |
| cpu | S18b, S19a | `fuxi cpufreq: d0 v15@2016 d1 v19@2803 d2 v20@3187 L3 v14@1804` with `sheng-cpufreq-turbo=1`, cpumask 0xff; smooth UI. S18a with E/P clusters and the Edge scheduler booted but was slower. |
| storage | every run | UFS root mounts; the Data volume keeps its contents across reboots (keepdata images). |
| display | every run | Home screen; GOP framebuffer with the GPU copy; DSI backlight. S15b: the lock screen poster (AegirPoster) makes IOSurface call an unmapped kernel function (panic). |
| input | every run | Touch and the power/volume buttons work. |
| gpu | S12q, S13, S18b | New GPU stack (Adreno740 upstream 2962e28 + fuxi, Turnip, AdrenoMetal, metal2vulkan 87a869f); about 5300 GPU submits, smooth. |
| network | S18b | Wi-Fi connected. |
| cellular | S14c, S19b | `FUXI_UIM: EF_ICCID ... EF_IMSI 46011...` (USIM ready); 49 QMI services; `COACHZ baseband: 22 of 22 services published`; `the radio: online not registered, searching`; logdump reports `com.apple.commcenter.carrierspace.xpc REGISTERED` and `MGCopyAnswer HasBaseband 0`. |
| audio | S14b | ADSP stage 13, audio stage 60. |
